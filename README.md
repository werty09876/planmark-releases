# PlanMark releases

Installers for **PlanMark**, the PDF plan viewer, takeoff and progress app for Windows.

This repository holds **releases only** — no source code. PlanMark checks here for updates by itself:
when a new version is published, it downloads it in the background and installs it the next time you
close PlanMark (after any unsaved work is dealt with).

To install PlanMark for the first time, download the latest `PlanMark Setup x.y.z.exe` from
[Releases](../../releases/latest).
